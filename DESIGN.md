# FAST Carpool design context

FAST Carpool is a safety-sensitive student utility. The visual language is calm and legible: midnight navy `#08111f` for trust, seafoam `#54e1b7` for verified/active states, paper `#f7fafc` for reading surfaces, and muted slate `#6b7788` for secondary copy. Actions use sentence case and explicit verbs. Destructive safety actions stay outlined and separated from primary ride actions. The signature is a quiet “verified” moment: a seafoam mark and plain-language status copy, never gamified praise.
